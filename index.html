3. Android Device Permissions & Core Purpose

To provide storage optimization and junk cleaning services, our app requests specific device permissions. In compliance with Google Play's Permissions and Storage Policies, each permission is used solely for its stated core utility purpose:

Permission Target API Specific Functional Purpose
MANAGE_EXTERNAL_STORAGE
(All Files Access)		 Android 11+
(API 30+)		 Core Functionality: Essential for a device cleaner. Allows scanning hidden system cache, residual files from uninstalled apps, temporary APK files, empty folders, and duplicate images across public storage directories.
READ_EXTERNAL_STORAGE / WRITE_EXTERNAL_STORAGE Android 10 and below Allows reading and deleting obsolete cache and residual junk files on legacy Android versions.
POST_NOTIFICATIONS Android 13+
(API 33+)		 Allows delivering clean completion summaries and optional storage optimization notifications.
INTERNET & ACCESS_NETWORK_STATE All versions Required for network connectivity to serve third-party Google AdMob advertisements and verify connection status.
